- Built the prompt-quality Evaluation page (TASK-014) — the project's culminating research feature. The page evaluates **the prompt**, not the questions and not the model: `buildPrompt`'s 7 sections each map 1:1 to a measurable dimension (count, structure, type, pattern, difficulty, reference alignment), so the headline score decomposes along the prompt's own structure and every finding points at an editable block of prompt text. Fully deterministic — no AI judge — so repeat evaluations are reproducible and a score change after a prompt edit is attributable to the prompt. Difficulty and reference alignment are clearly-labelled structural proxies (reasoning-step/operator counts, n-gram overlap) shown with their raw signals; dimensions that cannot be measured report N/A with weights renormalised. **Coverage is deliberately not scored** — the prompt says "Not every question needs to use every pattern", so incomplete coverage is surfaced as a prompt gap with a concrete suggested sentence, rather than as a model failure. Four flagship features: a Prompt Inspector showing the real prompt section-by-section with per-section verdicts, a per-question deviation evidence table, copyable prompt patches naming the exact file/constant to edit, and JSON/Markdown export for comparing runs across iterations. Required two small upstream changes: an optional `questionPattern` label on the AI output contract (pattern coverage was previously unmeasurable), and preserving the final prompt through `generateQuestions` instead of discarding it. All mock evaluation data and its 5 components were deleted. Verified live end-to-end (98% on a real Groq run, with the N/A renormalisation and difficulty-drift paths both exercised); 139/139 tests passing, `tsc`/`eslint` clean. Full report in `docs/agent-feedbacks/TASK-014-design-and-implement-prompt-quality-evaluation.md`.
